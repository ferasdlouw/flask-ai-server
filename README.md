
## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/ferasdlouw/flask-ai-server.git
cd flask-ai-server

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the server
python app.py
# Server starts at http://0.0.0.0:5050
```

## 📡 API Endpoints

| Method | Endpoint            | Description                          |
|--------|---------------------|--------------------------------------|
| POST   | `/transcribe`       | Upload audio → returns transcription |
| POST   | `/analyze-emotion`  | Send input → returns emotion result  |
